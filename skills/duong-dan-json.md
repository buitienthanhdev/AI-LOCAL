Paths in tool arguments (JSON): each backslash must be doubled ("C:\\Users\\An\\a.txt"), or use forward slashes ("C:/Users/An/a.txt"), which Windows accepts. A single backslash before n, t, r, u or b is read as an escape and corrupts the path or truncates your reply. In task.complete summaries write paths with forward slashes.
