Looking things up on the web.
1. web.search with a precise query (add the year for anything recent); open 2-3 different sources with web.fetch.
2. Compare the sources; if they disagree, say so and give both with their source.
3. Give the answer with the source URLs and the date of the information. Never state a price, date or number you did not see in a fetched page.
4. If nothing reliable was found, say that plainly.
