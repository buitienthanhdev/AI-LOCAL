- A named painting or a medium/style ("son dau", "but chi", "mau nuoc"): art.brief first (it identifies the work, picks the medium and mode, fetches a reference), then art.paint.
- Own composition: write an SVG with 40+ shapes (viewBox 0 0 1000 562.5), then art.draw; apply the REVIEW notes once.
- Say it is a simulation in Paint, not real oil/watercolour/lacquer.
- Say how close it is, with the measured number (match score / colour error) from the tool result. If the score is poor or the tool says the result is far from the reference, make ONE improvement pass (more detail, correct palette) before replying; never claim "giong" without a measurement.
