⚙ Bộ não AI

Trợ lý dùng lần lượt: Gemini API (nếu có khóa) → Gemini Web (tài khoản Google đã dán cookie) → AI trên máy (Ollama, chậm khi GPU đang bận). Gemini Web hay bị Google tạm chặn khi dùng nhiều; một khóa Gemini API miễn phí giúp trợ lý nhanh và ổn định hơn hẳn.

  1. Mở aistudio.google.com/apikey, đăng nhập Google, bấm Create API key.
  2. Bấm "Sao chép khóa", dán vào ô dưới rồi bấm Lưu. Khóa chỉ lưu trên máy này.
