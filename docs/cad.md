# 3D CAD from text (cad.build, cad.inspect)

Integrates [text-to-cad](https://github.com/earthtojake/text-to-cad) (MIT, Thompson Labs LLC): its `cadgen` package
generates parametric models with build123d on the Open CASCADE kernel and exports STEP, STL, GLB and 3MF.

## Install

```powershell
pwsh scripts/setup-cad.ps1        # uv venv runtime/cad (Python 3.13) + cadgen==0.7.21
pwsh scripts/fetch-references.ps1 # optional: the upstream repo (skills, docs) into references/text-to-cad
```

`runtime/` and `references/` are git-ignored. Without the runtime the tools answer `BACKEND_UNAVAILABLE` with the install line.
Reopen the chat window after installing so it lists the new tools.

## Tools

| Tool | What it does | Policy |
|---|---|---|
| `cad.build` | The planner writes build123d statements ending in `result = <shape>` (`bd` is build123d, millimetres, +Z up). The tool wraps them in a cadgen model script, builds it in `artifacts/<task>/cad/<name>-<time>/`, writes STEP (+ STL / GLB / 3MF), measures the solid and renders an isometric preview. | confirm in `normal`, allow in `trusted` / `full_access` |
| `cad.inspect` | Measures an existing `.step` / `.stp`: bounding box, volume, area, faces, solids, validity, preview. | allow |

Measured and checked by the tool, not by the model's say-so: bounding box, volume, face count, number of solids, validity.
`expected_size_mm` (the size the user asked for, any axis order) fails the call with the measured numbers when the model
differs by more than max(0.5 mm, 2 %); several solids fail unless `assembly` is true. A Python error comes back as the
traceback so the planner changes only the failing line.

## Planner support

* Planner rule 17 and the `cad-3d` playbook (`skills/cad-3d.md`): constants for every dimension, primitives, `bd.Pos` / `bd.Rot`,
  boolean operators, fillets after the last boolean, 3D-print clearances.
* Tool group `cad` is offered when the request mentions 3D, STEP, STL, 3MF, GLB, bracket, gear, enclosure and similar words.
* 2D plans and drawings stay with `autocad.*`; pictures stay with `art.*`.
